ЧАСТЬ 3. ПЕРЕВОД UNITY-ПРОЕКТА НА QUEST 3S (OPENXR)
================================================================================
3.1. Откройте проект: e:\diploma_maga\2\vr-crime-scene-main

3.2. Packages/manifest.json — удалите строки Pico, оставьте OpenXR и добавьте XR Management + XRI:

     УДАЛИТЬ:
       "com.unity.pico.livepreview": "...",
       "com.unity.xr.picoxr": "...",

     ДОБАВИТЬ (если отсутствуют):
       "com.unity.xr.management": "4.4.0",
       "com.unity.xr.interaction.toolkit": "2.3.2",
       "com.unity.xr.openxr": "1.9.1",

     Сохраните файл → Unity перезагрузит пакеты.

3.3. Edit → Project Settings → XR Plug-in Management:
     - вкладка Android: включите OpenXR;
     - снимите Pico XR (PXR), если остался после миграции пакетов.

3.4. Project Settings → OpenXR:
     - Android tab → Interaction Profiles: Oculus Touch Controller Profile;
     - Feature Groups → Meta Quest Feature Group → включите;
     - Target Devices: Meta Quest 3, Meta Quest 3S (и при необходимости Quest 2).

3.5. Edit → Project Settings → Player → Android:
     - Scripting Backend: IL2CPP;
     - Target Architectures: ARM64 (галочка только на ARM64);
     - Minimum API Level: 29 или выше;
     - Internet Access: Require;
     - Package Name: уникальный (например com.volggtu.crimescene.vr).

3.6. «MAC адрес» в веб-клиенте и на Quest:
     Сервер и страница /vr-headsets используют поле MacAddress (заголовок HTTP MacAddress).
     Это идентификатор гарнитуры (до 17 символов), без жёсткой проверки формата IEEE MAC.

     На Pico Neo 4 в VR обычно показывается реальный Wi‑Fi MAC (12 hex, например AABBCCDDEEFF).
     На Quest 3S реальный Wi‑Fi MAC приложению чаще всего недоступен (ограничения Android).
     Тогда Login.cs подставляет стабильный 12-символьный код в том же формате — его и нужно
     скопировать с экрана StartScene в поле «MAC адрес VR гарнитуры» в веб-клиенте.

     Важно: строка в вебе и на экране VR должна совпадать посимвольно, иначе будет 401.

3.7. IP сервера: Assets/Scripts/CurrentState.cs (по умолчанию 192.168.3.2).
     Укажите статический IP ПК в локальной сети или найдите его через ipconfig.

3.8. Сцены в Build Settings: StartScene.unity, CrimePhoto.unity (обе включены).

ЧАСТЬ 4. ПРОВЕРКА ВВОДА ТЕКСТА В VR (ФИО, ГРУППА)
================================================================================
Симптом: «не вводится текст» в полях TMP на StartScene.

Шаг 1 — кликабельность поля (луч контроллера попадает в UI):
- На Canvas: Tracked Device Graphic Raycaster (не Graphic Raycaster).
- Event System: XR UI Input Module (не Standalone Input Module).
- XR Ray Interactor (на Origin): Enable UI Interaction = On.
- У TMP_InputField: фон Image с Raycast Target = On; у placeholder-текста — Off.
- Компонент VrTmpInputFieldHelper на каждом поле (есть в проекте).

Проверка: при наведении луча поле подсвечивается; при нажатии Trigger — onSelect.

Шаг 2 — клавиатура Quest:
- После фокуса на поле Meta Quest обычно показывает системную клавиатуру.
- Если фокус есть, а символов нет: Settings → Physical Keyboard → включите виртуальную
  клавиатуру; пересоберите APK.
- В логе Unity (adb logcat) проверьте TouchScreenKeyboard.isSupported.

Шаг 3 — обход для отладки:
- Временно задайте ФИО/группу в Inspector на StartScene (только для теста);
- или используйте Meta Quest Link + клавиатуру ПК.

================================================================================
ЧАСТЬ 5. УПРАВЛЕНИЕ В VR (QUEST 3S, OCULUS TOUCH)
================================================================================
Правый контроллер:
- стик — зум панорамы;
- Trigger — аудиокомментарий;
- Grip — фотокомментарий.

Левый контроллер:
- кнопка A (Primary) — выход в меню;
- Y (Secondary) — предыдущая панорама;
- Grip — следующая панорама;
- стик влево/вправо — альтернативное переключение панорам.

Соответствие привязано к XRI Default Input Actions в проекте.

ЧАСТЬ 6. СБОРКА И УСТАНОВКА APK
================================================================================
6.1. File → Build Settings → Android → Switch Platform (если нужно).

6.2. Development Build + Script Debugging — для первых запусков (опционально).

6.3. Build And Run (шлем подключён, adb devices видит устройство).

     Альтернатива через MQDH: Deploy → Install APK.

6.4. На шлеме при первом запуске разрешите:
     - доступ к локальной сети (если запросит);
     - микрофон (для аудиокомментариев).

6.5. Если приложение не видит сервер:
     - ping с ПК: IP из CurrentState.cs;
     - отключите изоляцию AP на роутере;
     - Windows Firewall: разрешите входящие для порта 5197.

ЧАСТЬ 8. ТИПИЧНЫЕ ОШИБКИ
================================================================================
| Симптом | Решение |
|---------|---------|
| OpenXR не активен | XR Plug-in Management → Android → OpenXR |
| Чёрный экран в VR | Meta Quest Feature Group включён; сцена CrimePhoto в Build |
| 401 при meta | Неверный MAC в /vr-headsets — скопируйте строку с экрана VR |
| Не находит сервер | Один Wi-Fi, верный IP в CurrentState.cs, firewall |
| Нет клавиатуры | XR UI Input Module + фокус поля; системная клавиатура Quest |
| Пакеты Pico не находятся | Удалите com.unity.xr.picoxr из manifest.json |
